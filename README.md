# Abhinavkrishnan M — Personal Portfolio

A sleek, modern developer & data analyst portfolio website designed in **dark mode with crimson red accents**, matching the reference UI inspiration.

---

## 🚀 Quick Start (Zero Dependencies)

You can view the portfolio immediately in any web browser without needing to run builds or install packages:

1. **Directly Open:**
   Double-click `index.html` or right-click `index.html` → **Open with** → **Google Chrome** / **Edge**.

2. **Or with a Local Development Server:**
   ```bash
   # Using Python 3 built-in server:
   python -m http.server 3000

   # Or using Node / npx:
   npx serve .
   ```
   Then open `http://localhost:3000` in your browser.

## 🎨 Design System & Customization

- **Background**: Deep matte black (`#08080a`) with dark charcoal cards (`#111114`).
- **Accent**: Vibrant crimson red (`#e50914`) with glowing hover states.
- **Typography**:
  - `Anton`: Heavy condensed headline watermark ("PORTFOLIO") and names.
  - `Caveat`: Authentic cursive script for *"Hello, I'm"* and signatures.
  - `Plus Jakarta Sans`: Modern clean body font.
- **To add your own portrait photo:**
  Save your photo as `avatar.jpg` in this directory, and update line 220 of `index.html` to point to `avatar.jpg`.

## 🛠️ Deploying Online

You can deploy this portfolio for free in under 60 seconds:

### Option A: GitHub Pages
1. Push this folder to a GitHub repository (e.g., `github.com/abhinavkrishnan8129/portfolio`).
2. Go to repository **Settings** → **Pages** → Source: **Deploy from a branch (main / root)**.

### Option B: Netlify / Vercel
- Drag and drop this folder directly into the [Netlify Drop](https://app.netlify.com/drop) or import into [Vercel](https://vercel.com).
